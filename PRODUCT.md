# Product

## Register

product

## Users

Captains and local operators supervising a Firstmate fleet use this surface during focused planning and live operational review, often on a desktop in a dim room. They need a fast whole-company read, then a direct path to one workstream, task, agent, or event without leaving the local machine.

## Product Purpose

AI Company OS provides independent role routing, private local persistence, bounded run state, policy gates, and evidence-preserving handoffs. The AI Company dashboard is its read-only Firstmate observability surface: Flowline supports daily planning, Operations Constellation explains live work topology, and Event Ledger supplies chronological evidence. Success means current state is visibly distinguished from historical events, local fleet changes appear without reload, and no private report body or credential crosses the dashboard boundary.

## Brand Personality

Precise, restrained, operational. The voice is terse but humane, technically credible without militarized or alarmist language. The interface should inspire calm command of a complex local system rather than spectacle.

## Anti-references

- Generic SaaS admin dashboards built from oversized metric cards and repeated identical card grids.
- Decorative sci-fi radar, empty globe imagery, neon cyberpunk glow, or defense targeting and weapons language.
- Glassmorphism, gradient text, decorative gradients, pure black, pure white, and remote-font dependence.
- Hidden role handoffs, speculative control planes, intervention controls, or any UI that weakens the repository's explicit routing and privacy boundaries.
- Surfaces that treat append-only status entries as current truth or expose private report bodies, prompt files, raw local paths, secrets, or credential values.

## Design Principles

1. **Truth before theater.** Reconcile live state through the authoritative Firstmate boundary and label history as history.
2. **Plan first, observe deeply.** Open in Flowline, preserve whole-company context, and make live topology and chronology one deliberate mode change away.
3. **Meaningful density.** Every route, node, label, and metric must answer an operator question; decoration never impersonates data.
4. **Local and read-only.** Bind to loopback, expose only a sanitized projection, and keep operational controls outside the initial release.
5. **Bound every stream.** Retention, animation, listeners, child processes, and rendering work all have explicit ceilings and cleanup.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Every state has a text label and non-color cue. All navigation, filters, agent selection, inspector actions, and new-agent acknowledgement work from the keyboard with visible focus. The surface supports narrow mobile through wide desktop layouts, browser zoom, reduced motion, persistent static mode, and useful loading, empty, reconnecting, unavailable, and error states.
